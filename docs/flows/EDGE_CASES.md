# Edge Cases

狀態：draft  
最後更新：2026-08-13

## 資料為空
- 使用者未提供足夠資料時，仍可先提交預約申請，但需由老師人工補問。
- 基本資料與服務候選欄位分開處理；專業資料不足時，不要求使用者一次填完全部內容。
- 婚嫁新人出生年月日時、新生兒出生資料、搬遷舊址／新址等目前屬候選欄位，均為 `Proxy Assumption` 的選填候選，真正必填規則屬 `Pending Owner Validation`。
- 缺少專業資料時，狀態可為「待補資料」，不直接顯示「預約失敗」。

## 外縣市／到場／多地點
- 外縣市、跨縣市、多地點與老師到場案件不自動計算費用。
- 由老師人工確認是否承接、服務費、諮詢費、車馬費與安排方式。
- 宜蘭縣內是否有固定到場範圍與費用規則，仍待確認。
- 到場欄位只在入宅／搬遷、神明／祖先與宅事／到場諮詢等適用服務中主動顯示。
- 若使用者選擇需要到場，收集縣市／地區（必填）、完整地址（可後補）、多地點與是否方便協助接送等資訊。
- 宜蘭以外可先提供地點與服務內容，是否承接與交通安排由老師人工確認。

## 特殊案件
- 神明／祖先牌位遷移、祭拜相關需求與其他特殊案件，先收集情境與地點，再由老師確認服務範圍。
- 不在網站自動判斷專業結果或直接承諾可以承接。

## 入宅／搬遷與宅事重疊
- 以「我要安排搬家／入住日期」為主要需求時，歸入入宅／搬遷擇日。
- 以「請老師到房屋現場查看空間／位置／宅事」為主要需求時，歸入宅事／到場諮詢。
- 兩者同時發生時，保留一個 Primary Service，另加 Additional Need「同時涉及到場諮詢」，不要求使用者提交兩張申請。

## 案件狀態
- `Booking Request`：網站、LINE 或電話提出的需求，尚未成立案件。
- `待人工確認`：老師正在確認需求、資料與是否承接。
- `待補資料`：需要使用者補充資料。
- `Confirmed Case / Appointment`：雙方完成服務、費用與日期／安排確認後的正式案件（`Proxy Assumption`，仍待業主最終確認）。
- `無法承接／另行說明`：不屬於服務範圍或目前無法安排，由老師人工說明。

## 費用與付款
- 第一次送出預約申請不付款；老師人工確認服務內容、服務總價與日期／時間後，才建立綠界預約訂金交易。
- 預約訂金級距為：服務總價 NT$5,000 以下收 NT$800；NT$5,001～8,000 收 NT$1,200；NT$8,001 以上收 NT$1,600。
- 尾款為服務總價扣除已付訂金，付款成功後需顯示尾款明細。
- 特殊案件是否適用級距、取消／退款／改期規則、尾款收取時間與方式仍依人工確認結果處理。
- 不提供完整服務費一次付清、購物車或電商式 Checkout；綠界只處理人工確認後的預約訂金。

### 付款失敗／取消
- 綠界付款失敗或使用者取消付款時，不得標記為 `Deposit Paid`。
- 保留原 `Booking Request`，提供重新付款或 LINE／電話聯繫入口。
- 不得在付款失敗／取消畫面顯示「預約成功」。

## 請求失敗
- 表單送出期間顯示 Loading State 並暫時避免重複送出。
- 表單送出失敗時，需保留使用者已填資料、提供 Retry，並提供 LINE／電話等替代聯繫方式；正式錯誤文案待確認。
- 未勾選資料使用 Checkbox 時，需阻止送出並清楚提示同意用途；不得以模糊的「同意所有條款」取代。
- Google Sheet 或 Email 通知失敗的實際告警、重送與人工處理方式尚待技術／業主確認。

## 資料接收與存取
- 預約申請暫經 Google Apps Script 寫入私有 Google Sheet，初始狀態為 `New／待確認`；Email 僅可作新申請通知。
- Google Sheet／後台不得公開存取；預約資料僅供預約聯繫、服務確認與相關溝通使用。
- Google Account 擁有者、Email 收件人、資料保存期間與刪除／管理流程均待業主確認。


## 使用者中斷流程
- 使用者可先離開服務介紹或預約表單，改用 LINE／電話詢問。
- 預約表單是否需要保存草稿，待後續確認。

## 日期與聯絡時間混淆
- 「希望辦理期間／候選日期」是事件日期需求。
- 「方便聯絡時間」只是聯絡偏好，不代表正式預約時段。
- 使用者尚未確定日期時，可選擇由老師協助確認，不顯示自動推薦日期。

## 急件
- 使用者可標記「時間較急，希望老師優先確認是否可承接」。
- 這只是 Urgency Signal，不代表保證優先、一定承接或一定加費。
- 急件定義與處理方式待業主確認。

## 修改／改期
- 老師尚未開始作業前：鼓勵使用者盡早聯繫更新資料、日期區間或地址。
- 老師已開始處理後：更改日期條件、主要需求、地點或服務內容，可能需要重新處理、重新安排或重新報價。
- 不預先承諾免費修改、無限次修改或固定退款。

## 交付與時程未定
- 若交付格式尚未確認，不顯示固定紙本、電子檔、郵寄、LINE 圖片或固定名字數量。
- 若完成時間尚未確認，使用「確認案件時說明」，不顯示固定天數。

## 回復方式
- 資料不足：由老師人工補問。
- 無法承接：由老師人工說明並提供適當聯繫回覆。
- 需要改期／取消：依人工確認的規則處理，正式規則待確認。

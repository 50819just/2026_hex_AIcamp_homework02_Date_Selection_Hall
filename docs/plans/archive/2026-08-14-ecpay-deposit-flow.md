# 綠界預約訂金流程規格計畫

## 目的

將玄機堂由「人工安排付款」調整為「老師確認服務與總價後，使用綠界收取分級預約訂金」，並保留人工確認與尾款說明流程。

## 範圍

- 更新 `docs/Spec.md` 的付款策略、預約流程、狀態與驗收條件。
- 訂金只允許 NT$800、NT$1,200、NT$1,600 三種級距。
- 不新增完整服務費一次付清、購物車或自動報價。
- 取消、改期、退款與尾款實際收取方式維持待確認。

## 完成條件

- Spec 明確描述 4-Step 表單與後續人工確認、綠界付款、尾款說明的順序。
- Spec 明確描述三段訂金級距與 5,000 元服務案例。
- 未確認的退款、改期、尾款政策仍標示為 Pending，不自行補定。

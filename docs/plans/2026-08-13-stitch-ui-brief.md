# Stitch UI Design Brief 產出計畫

日期：2026-08-13  
狀態：完成

## 目標

依既有 Confirmed、Proxy Assumption 與 Pending 邊界，建立可直接交給 Stitch 的完整 UI Design Brief，先產出核心轉換頁面與高優先手機版。

## 範圍

1. 整理品牌、視覺、資訊架構、服務、價格、預約與 RWD 要求。
2. 明確標示可用 placeholder 與不得虛構的內容。
3. 定義 Batch A 與 Batch B 畫面，以及可重用元件與狀態。
4. 僅新增設計 handoff 文件，不修改 React Prototype。

## 驗證

- UI Brief 含完整頁面、流程、表單、文案、視覺、RWD 與禁則。
- 已知的 Confirmed 與 Proxy Assumption 不混淆。
- 所有未確認資料均採 placeholder 或保守文案。

## RWD 補強（2026-08-13）
- 在 Stitch 核心指令中明確指定 Desktop 1440 px、Tablet 1024 px、Mobile 375 px 三個斷點。
- 補上各斷點的版面重排與不可省略內容規則。

## Spec 規則對照補強（2026-08-13）
- 將既有 Confirmed、Proxy Assumption、Pending 與技術邊界，以 UI 可執行對照表補入 Stitch Brief。
- 讓 Stitch 可直接判斷哪些規則必須畫出、哪些只能保守呈現、哪些不可自行補造。

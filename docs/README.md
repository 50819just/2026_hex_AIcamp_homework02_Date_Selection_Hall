# 文件索引

## 目前結構
- `design/`：設計稿、截圖、共享連結與設計決策。
- `e2e/`：E2E 錄影連結、測試結果與證據。
- `specs/`：產品規格、使用者流程、資訊架構、設計方向與逐頁 spec。
- `requirements/`：MVP、非功能與內容需求。
- `flows/`：主流程、例外流程、狀態轉換。
- `research/`：參考案例、競品與觀察筆記。
- `decisions/`：ADR 與重要決策記錄。
- `backlog/`：未排進本期的功能與想法。
- `templates/`：可重用文件模板。
- `ARCHITECTURE.md`：前端、金流與資料流架構。
- `TESTING.md`：人工與自動化測試條件。
- `UI_BUILD_READINESS_REVIEW.md`：文件與目前 React prototype 的 UI 建置就緒度檢查。
- `plans/`：進行中與已完成的執行計畫。

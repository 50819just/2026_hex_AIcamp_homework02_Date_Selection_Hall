# Specs 索引

這裡放產品與頁面層級的規格文件。

## 檔案清單
- `PRODUCT_SCOPE.md`：產品定位、目標、範圍與非目標。
- `USER_FLOW.md`：主要使用者流程與關鍵節點。
- `SERVICE_CATALOG.md`：服務清單、適用情境、所需資料與交付內容。
- `BOOKING_FLOW.md`：預約流程、表單欄位與人工確認節點。
- `PRICING_POLICY.md`：價格揭露方式、改期與退款規則。
- `DOMAIN_RULES.md`：內容語氣、專業邊界與風險控管原則。
- `FAQ_SPEC.md`：常見問題分類、回答方向與補充說明。
- `COPY_TONE_GUIDE.md`：品牌語氣、推薦用詞與 CTA 方向。
- `ABOUT_BRAND_SPEC.md`：關於頁架構、品牌介紹與信任建立內容。
- `INFORMATION_ARCHITECTURE.md`：頁面、區塊、導覽與資訊架構。
- `DESIGN_DIRECTION.md`：視覺方向、語氣、設計原則。
- `DESIGN_SPEC.md`：Design Style、token、按鈕、元件與 RWD。
- `DEMO_VISUAL_ASSET_SPEC.md`：Demo 影像、人物／個案標示與檔案規則。
- `pages/CORE_SCREEN_REQUIREMENTS.md`：22 張正式畫面的 route / state 與驗收規格。
- `pages/`：單頁規格與頁面模板。

## 使用方式
1. 先寫 `PRODUCT_SCOPE.md`。
2. 再補 `SERVICE_CATALOG.md`、`BOOKING_FLOW.md`、`PRICING_POLICY.md` 與 `DOMAIN_RULES.md`。
3. 再補 `USER_FLOW.md` 與 `INFORMATION_ARCHITECTURE.md`。
4. 依 `pages/README.md` 的順序建立逐頁 spec：Home → Service Detail Template → Booking → Pricing → Services Listing → About → FAQ / Contact。

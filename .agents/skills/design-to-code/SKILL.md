# Design to Code Skill

## 目標
1. 使用已連接的設計工具 MCP 產出花店商品、結帳、訂單確認或付款完成頁設計稿。
2. 將設計稿截圖、共享連結或原始檔記錄至 `docs/design/`。
3. 依設計稿實作 React 響應式介面，不直接複製第一場作業的舊畫面。

## 流程
1. 先讀取現有頁面、資料流與 `docs/design/README.md`。
2. 確認目標頁、桌機與手機斷點、品牌色彩與元件清單。
3. 透過 MCP 產生或更新設計稿，保存證據與設計決策。
4. 先建立可重用元件，再完成頁面與互動。
5. 以桌機、平板、手機檢查畫面，執行 build 與 lint。

## 交付條件
- 設計稿與實作頁面可一一對應。
- 至少涵蓋商品、結帳、訂單確認或付款完成其中一條完整流程。
- 不把任何 ECPay 金鑰或個資放進前端或設計檔。

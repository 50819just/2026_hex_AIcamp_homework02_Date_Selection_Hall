# E2E Payment Test Skill

## 測試目標
驗證商品頁到付款結果頁的完整金流流程，以及欄位驗證與未登入結帳的異常情境。

## 前置條件
- 前端與本地 API server 均已啟動。
- 使用測試環境、測試帳密與測試付款資料；不得使用正式付款資料。
- 錄影前先確認瀏覽器自動化工具可操作本機頁面。

## 正常流程
1. 開啟商品頁，加入商品至購物車。
2. 未登入時嘗試結帳，確認被導向登入。
3. 以測試會員登入，回到結帳頁。
4. 填寫配送、付款與發票欄位；確認同意條款 checkbox 可正常操作。
5. 建立 ECPay 測試訂單，進入綠界測試付款頁。
6. 完成測試付款後回站，主動查單並確認付款成功資訊。

## 異常情境
- 必填收件資料缺漏時不得建單。
- 未勾選同意條款時不得建單。
- 缺少訂單編號或查單失敗時需顯示可讀錯誤訊息。
